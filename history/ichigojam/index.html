今の弾よけゲームを残したいとき
  1. FILES と入力する
  2. 空いている番号を大人と確認する
  3. SAVE 番号 で保存する

分からないときは、まだ NEW を入力しません。

ゲームを入力してみよう

1行ずつ入力して Enter。全部入ったら RUN です。

ゲーム1　反応そくど

「GO!」が出たら、すぐに何かのキーを押します。

10 CLS:?"READY..."
20 WAIT 60+RND(180)
30 CLK
40 CLS:?"GO!":CLT
50 IF INKEY()=0 GOTO 50
60 T=TICK()
70 CLS:?"TIME=";T
80 BEEP 10,10
90 END

変えてみよう：20行の 180 を大きくすると、GO!を待つ時間が長くなります。

ゲーム2　いちごキャッチ（オリジナル）

← → で「U」を動かし、落ちてくる「O」を受け止めます。3回取りのがすと終了です。

10 CLS:X=15:S=0:H=3
20 A=RND(32):Y=1
30 LOCATE A,Y:?"O"
40 LOCATE X,21:?"U"
50 WAIT 4
60 LOCATE A,Y:?" "
70 LOCATE X,21:?" "
80 X=X-BTN(LEFT)+BTN(RIGHT)
90 IF X<0 X=0
100 IF X>31 X=31
110 Y=Y+1
120 LOCATE 0,0:?"S=";S;" H=";H
130 IF Y<21 GOTO 30
140 IF A=X GOTO 170
150 H=H-1:BEEP 30,10
160 IF H>0 GOTO 20
165 GOTO 200
170 S=S+1:BEEP 10,5
180 GOTO 20
200 CLS:?"GAME OVER"
210 ?"SCORE=";S
220 END

変えてみよう：10行の H=3 を H=5 にすると、5回まで遊べます。

ゲーム3　ほしとばくだん（オリジナル）

星「*」は取り、爆弾「X」はよけます。← → で「U」を動かします。

10 CLS:X=15:S=0:H=3
20 A=RND(32):Y=1:T=RND(5)
30 IF T=0 GOTO 50
40 C=42:GOTO 60
50 C=88
60 LOCATE A,Y:?CHR$(C)
70 LOCATE X,21:?"U"
80 WAIT 4
90 LOCATE A,Y:?" "
100 LOCATE X,21:?" "
110 X=X-BTN(LEFT)+BTN(RIGHT)
120 IF X<0 X=0
130 IF X>31 X=31
140 Y=Y+1
150 LOCATE 0,0:?"S=";S;" H=";H
160 IF Y<21 GOTO 60
170 IF A<>X GOTO 20
180 IF T=0 GOTO 210
190 S=S+1:BEEP 10,5
200 GOTO 20
210 H=H-1:BEEP 30,10
220 IF H>0 GOTO 20
230 CLS:?"GAME OVER"
240 ?"SCORE=";S
250 END

変えてみよう：20行の RND(5) を RND(3) にすると、爆弾が増えます。
