# 写真で補修部品相談 — ホシ姫サマ実証版

壊れた部品の名前・図面・材質が分からなくても、**写真4枚と簡単な質問だけ**で補修部品の相談内容を整理する、スマートフォン向けの最小実証版です。

## 目的

- 依頼者はCAD、STL、公差、樹脂名を考えなくてよい
- 最初の実証対象は「ホシ姫サマ」周辺の樹脂部品
- 写真から不足情報だけを後から分かりやすく尋ねる
- 重大事故につながる部品は自動で慎重判定へ回す
- 一度完成した設計を品番化し、次の人には受注生産で届ける

## 現在のMVP

- 写真4枚の撮影ガイドと端末内プレビュー
- 製品名・型番・症状・使用環境の簡単入力
- 直射日光、屋外、熱、荷重、電気周辺などのリスク確認
- 入力途中の端末内自動保存
- 相談整理票の生成、コピー、メール下書き、JSON保存
- iPhone向けのモバイル優先画面
- 外部送信なし。写真は端末内でのみプレビュー

## 使い方

1. `index.html`をブラウザーで開く
2. 製品全体、壊れた部分、取付場所、大きさ比較の写真を選ぶ
3. 分かる範囲で故障状況と使用環境を入力
4. 相談整理票を確認し、コピーまたはメール下書きを作る

写真のバイトデータは保存・送信されません。ページを再読み込みすると写真は選び直しですが、文章入力は同じ端末のブラウザーに残ります。

## ローカル起動

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000`を開きます。

## ファイル

- `docs/CODEX_HANDOFF_JA.md` — Codex向けの次段階仕様

## 安全境界

初期販売候補は、カバー、ノブ、キャップ、ガイド、スペーサーなどの低危険部品です。制動、操舵、座席固定、頭上重量物、100V以上、転落や挟まれに関係する部品は、自動承認・自動製造の対象にしません。
