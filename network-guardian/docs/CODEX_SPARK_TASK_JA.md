## 目的

`network-guardian/` のMVPを、壊さず・小さく・テストを増やしながら改善する。

## Sparkに任せる範囲

1. `tests/` の追加
2. macOS / Linuxのping出力差のテストケース追加
3. Web UIの小さな改善
4. SQLiteクエリの整理
5. 型・例外処理・READMEの整合性修正
6. 1変更ごとにテストを実行

これらは設計レビューとGO確認後に別Phaseで扱う。
